# Integro Box languages

The interface supports Portuguese (`pt` / `pt-BR`), English (`en` / `en-GB`) and German (`de` / `de-DE`). Portuguese remains the authored source and default. The flag button is available on the landing page, sign-in page, IntGem page and catalog header; account settings and the Pegue o Ovo menu also expose it.

## Translation assets

`locales/*.json` domain files map an exact Portuguese source phrase to `[English, German]`. `en.json` and `de.json` are generated single-language runtime dictionaries. Rebuild with:

```
node tools/i18n/build.mjs
```

Keep numbered placeholders such as `{0}` and `{3}` intact. The build checks placeholder identity. Add full phrases before relying on compound fragments, especially for grammar and dynamic counters. `i18n.js` performs exact phrase matching, parameterized phrase matching and compound-label matching; it keeps source text separately so Portuguese can be restored.

`i18n.js` observes new interface content, translates accessible labels and placeholders, and formats displayed Portuguese-style numbers for the chosen locale. It never changes input values, option values, account IDs, game storage or messages written by players. User names, ranking names, chat messages and exercise answer text are excluded from DOM translation. Canvas text is translated when drawn. The selector saves progress through the games' existing `pagehide` hooks and reloads the game page into its catalog, so canvas textures and educational vocabulary are recreated in the selected language. Other entry pages switch in place. The saved language uses the device-local `integro-box-language-v1` key.

`classic-games.js` has dedicated answer banks for Word Bridge (24 words per language). English Memory preserves its educational language pairs: English/Portuguese in Portuguese and English interfaces, English/German in the German interface. Matching uses stable indices, not translated labels.

## Covers

Seven Portuguese-titled games have English and German SVG covers in `assets/catalog-i18n/`. Each SVG embeds its original artwork and renders its translated title as SVG text. Branded game titles stay unchanged. `manifest.json` records title/path pairs. Portuguese restores the original artwork, including the custom robot-route SVG.

## Verification

```
node --test tests/box-i18n.test.mjs
```

The tests cover language persistence, dynamic UI, numbers and templates, canvas text, reversible covers, translated catalog search, unchanged user data and form values, failure fallback, dictionary placeholders and self-contained cover assets. The covers have also been rendered and visually inspected as SVG artifacts. Browser-based UI/layout QA was unavailable in the managed environment; verify compact header spacing, the language dialog and longer German labels on representative mobile devices.
